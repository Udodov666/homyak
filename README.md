# Хомобот

Расширение для Chrome, которое отвечает за тебя на форуме — в стиле любительХомиака.

## Установка

1. Скачай ZIP (зелёная кнопка **Code → Download ZIP**) и распакуй.
2. Открой `chrome://extensions`.
3. Включи **Режим разработчика** (справа сверху).
4. Нажми **Загрузить распакованное расширение** и выбери распакованную папку.
5. Кликни по иконке расширения → вставь свой API-ключ FastAIToken → **Сохранить**.

## Как пользоваться

На странице темы в ряду иконок редактора появится иконка робота. Нажми — Хомобот прочитает тему (и кому ты отвечаешь) и вставит готовый ответ в редактор. Остаётся отправить.
